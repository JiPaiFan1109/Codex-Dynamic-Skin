# 0.2.0 上线前清理审查

日期：2026-10-13。目标：只分发完整换肤管理中心和必要的本地换肤引擎，移除不再使用的上游应用功能；保留安全校验、回滚和旧状态恢复。

## 审查方法与范围

- 核对 `scripts`、`engine/scripts`、`engine/assets`、安装定义、构建白名单、测试、README 及第三方声明；发行包不通过目录通配符收集工作区文件。
- 使用 PowerShell AST 提取函数定义，结合生产入口、直接调用和字符串引用追踪依赖；忽略注释中的名称，人工复核未被当前流程调用的候选。测试专用替身不作为产品功能的调用证据。
- 检查 JavaScript 模块依赖、CLI 分支、实际生成的渲染载荷、默认主题、预设初始化、网络目的地与旧托盘路径。
- 核对应用图标与本机最后确认的透明 ICO 相同；README PNG 来自同一 ICO。界面截图使用临时壁纸库和实际 Codex 安装检测生成，没有更改用户当前壁纸。
- 构建后检查 ZIP 内容与哈希；同一安装定义的隔离包实际执行 EXE 启动、安装、升级、旧文件清理及卸载。

## 已移除或简化

| 部分 | 处理 |
| --- | --- |
| 旧托盘 | 移除托盘路径描述、互斥量探测、托盘停止函数及恢复时调用；没有托盘菜单、托盘启动入口或相关运行脚本 |
| 上游安装器 | 移除未调用的旧引擎安装函数及其要求的缺失上游素材、社区入口和更新检查脚本清单 |
| 社区功能 | 移除固定上游社区 API、URL 协议解析、社区元数据处理和未使用的提示文案 |
| 旧主题包/选择器 | 移除主题 ZIP 导入、保存/选择旧主题及相关未调用函数；移除大型 ZIP/manifest 校验器，当前图片/视频输入仍保留必要校验 |
| 上游预设 | 停止生成上游预设副本、检测缺失预设目录及删除特定旧主题目录；不删除用户已有主题或媒体 |
| 重复图片归档 | 停止将每次应用的图片再次复制到旧图片收藏目录；保留管理中心壁纸库和渲染所需的活动主题副本 |
| 旧完整样式 | 移除读取但未用于最终注入的 `dream-skin.css`，最终载荷仅使用项目自己的背景样式 |
| 多余渲染处理 | 移除未使用的自动取色/构图分析、品牌文字/字体/配色变量改写及社区边框桥接；恢复时不再清除非本次写入的原生样式变量 |
| 旧操作端点 | 移除没有当前调用方的 begin/finish 操作端点；保留实际使用的应用、移除、监视、验证和诊断链路 |
| 文档与素材 | README 按应用介绍、界面/功能、更新时间、使用、技术、许可、收款码重排；统一使用最后确认的透明图标 |

清理移除了 **48 个未调用的 PowerShell 函数**。以本次应用开发完成、清理前的引擎源文件为基线，文本源码从 **13,610 行 / 607,624 字节** 减至约 **8,642 行 / 378,287 字节**（不含媒体和 Node 运行环境；末轮注释调整会造成少量变化）。

## 必要保留的逻辑

- 注册包身份、路径/重解析点、进程归属及本地调试端点验证，避免对无关程序操作。
- 媒体大小、类型、图像尺寸、哈希和旧主题 CSS 安全校验；旧媒体格式与状态字段兼容。
- 互斥锁、应用结果校验、失败/取消回滚、用户确认和恢复原始外观。
- 旧安装迁移，以及已存在的主题替换/外观配置事务恢复。当前界面不创建这些旧事务，读取恢复能力用于保护此前状态。
- `DreamSkin` 名称在内部协议、旧状态字段和必要函数中继续保留，避免升级时打断兼容；不表示保留旧托盘或社区应用。

## 防回归与边界

- 默认素材为项目生成的 Night Sky；人物预设相关文字只允许出现在防回归测试或审查说明中，不进入运行资源。
- 新增测试验证无旧功能导出、不会生成旧预设或删除用户主题、原生字体变量不被改写、没有无效图片分析、旧端点拒绝调用以及发行包排除旧资源。
- 安装升级只删除明确列举的旧运行文件，不清空用户壁纸库、迁移素材或备份；本地历史发行目录和验证证据不进入公开源码或安装包，也不作为活动运行路径。
- 本轮没有重启正在工作的 Codex 会话或切换其实际壁纸。自动化测试、真实媒体播放与隔离安装验证不能替代用户在其他 Codex 版本上的兼容性验收。
