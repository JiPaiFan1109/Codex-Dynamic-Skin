应用内更新现已可用

- 打开管理中心后自动检查新版，每天最多检查一次；也可点击“检查更新”。
- 新版提示包含更新说明，支持“立即更新”“稍后”和“跳过此版本”。
- 点击更新后自动下载、校验签名和安装包，退出管理中心完成升级，再重新打开。无需手动寻找和运行安装包。
- 升级保留壁纸收藏与设置，不会自动关闭 Codex 或重启电脑。遇到无法确认归属的进程占用时会停止安装。
- 下载失败、清单签名无效或安装包损坏时停止更新。

旧版本用户请先手动安装一次 v0.3.0，此后可在应用内获取更新。应用未运行时不会接收通知；也可在 GitHub 仓库选择 Watch → Custom → Releases 订阅发布消息。

安装后可从“打开 Codex”重新连接换肤。后台仍会下载完整安装包，本版不含增量更新。
