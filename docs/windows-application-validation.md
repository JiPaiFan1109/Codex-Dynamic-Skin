# Windows 安装应用验证记录

日期：2026-10-13，版本：0.2.0。

- 环境：Windows x64、Windows PowerShell 5.1、WPF、固定 Node.js 24.19.0，Inno Setup 7.1.0 x64。
- Node 测试 20 项，Windows PowerShell 测试文件 30 个，涵盖真实媒体转换、库操作、并发、应用取消与失败回滚、启动器及恢复结果校验，并新增上游残留、原生变量保留及旧操作端点关闭的回归检查。
- 新增检测测试覆盖有效官方包、缺失/检测失败、按钮可用性及状态控件。本机只读检测实际找到官方 Codex 26.1007.2314.0。
- 新增卸载守卫测试覆盖无状态、活动换肤时拒绝静默卸载、取消恢复、成功恢复，以及已经恢复但保留主题文件时允许静默卸载。
- 生产安装程序拒绝指定自定义安装目录，EXE 校验文件与实际内容匹配；应用文件带有管理中心名称和专用图标。
- 同一安装定义的隔离测试包真实执行安装、升级和卸载：中文路径安装成功；已安装应用文件与生产载荷哈希逐一一致；直接启动已安装的 `CodexSkinManager.exe --prepare-only`，确认其子进程打开真实 WPF 管理窗口并正常退出；升级及卸载后壁纸库测试数据保留。
- WPF 集成测试真实执行图片/视频导入、过滤、播放、重命名和删除；生成界面截图并检查新增连接状态和重新检测按钮。

隔离测试使用独立临时安装目录和卸载登记 ID，没有覆盖本机日常安装。本轮没有重启当前 Codex 会话或切换其真实壁纸；实际换肤依赖项目原有引擎，已有自动化验证覆盖该引擎及管理中心调用、结果校验和回滚路径。发布验证不能替代用户在其客户端版本上的完整操作验收。

构建与运行方式见 [Windows 安装应用](windows-application.md)。
