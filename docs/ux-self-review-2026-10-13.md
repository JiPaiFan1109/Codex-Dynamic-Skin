# Windows 使用体验自查与修复

日期：2026-10-13。审查基线：公开 v0.2.0，提交 `6ae6bc13807e9405b14e81333af84674292200cd`。修复版本：0.2.1。

本轮没有在用户电脑安装、运行应用或执行回归测试。源码阅读和修改在工作区完成，执行验证放在 GitHub 托管的隔离 Windows 环境中。该环境不具备登录后的真实 Codex 会话，因此结果不等于真人换肤验收。

## 已确认并修复

| 问题 | 用户可能遇到的表现 | 修复 |
| --- | --- | --- |
| 取消分支缺少返回结果 | 取消重启后被当作故障，并可能再次要求重启 | 两个取消分支写入明确结果；取消只恢复文件，不重新应用；界面显示取消状态 |
| 进度提示函数被误删 | 进入部分显式操作分支时发生未定义函数错误 | 补回辅助函数，提示更新失败不影响换肤操作本身 |
| 恢复缺少幂等判断 | 未换肤或已恢复时仍可能要求重启普通 Codex | 没有受管会话且外观已经恢复时直接结束，不启动恢复引擎 |
| 升级未检查后台占用 | 后台 Node 仍运行时替换文件失败，安装可能中断 | 在替换及删除前只读检查，提示先恢复外观并退出；不自动终止进程 |
| 卸载恢复早于卸载确认 | 用户尚未确认卸载就可能改变 Codex 外观 | 恢复放到确认之后、文件删除之前；取消通过专用结果安静中止 |
| 取消/失败重复弹窗 | 取消恢复后连续出现脚本与安装器的警告 | 取消不按故障处理，真正失败由安装器提示一次，应用和收藏保留 |
| 忙碌时关闭窗口弹框 | 每次尝试关闭都被弹窗打断 | 保留任务保护，改成窗口内提示 |
| 丢弃具体失败原因 | 用户只看到退出码或内部分类，不知道如何处理 | 优先读取结构化结果，保留失败原因，并对常见原因显示中文操作建议 |

新增回归用例先在隔离环境复现失败，再检查修复。还核对了项目 PowerShell 命令的定义与调用，未发现当前命名调用引用缺失函数。

## 保留的必要提示

- 操作确实需要关闭或重启 Codex 时，保留一次确认，避免未保存输入或运行中的任务被意外中断。
- 删除壁纸的确认、真实操作失败的提示继续保留；不以隐藏错误来减少弹窗。
- 后台正在转换或导入时，仍阻止直接关闭窗口，避免产生不完整文件。

## 仍需真人关注

- 首次安装识别 Codex、静态/动态切换、真正的外观恢复及不同 Codex 版本兼容性。
- 视频解码依赖 Windows 媒体组件；隔离检查不能证明所有用户视频都能播放。
- 长视频导入仍无取消功能，第二次启动管理中心仍采用已打开提示；这两项保留为后续体验改进，不通过强制结束进程处理。

同学测试前先保存 Codex 工作，使用最新版下载链接。遇到问题记录操作顺序、完整提示截图、Codex 版本及收藏是否保留。
